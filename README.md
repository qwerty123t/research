# research

Статический сайт с индексом исследований. Публикуется на GitHub Pages при пуше в `main` через GitHub Actions.

Адрес после публикации: `https://<логин>.github.io/research/`

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка страницы: шапка, блок «Записи», подвал |
| `styles.css` | Оформление: шрифты, светлая/тёмная тема, анимации |
| `script.js` | Переключатель темы, подсчёт записей, год в подвале |
| `.github/workflows/pages.yml` | Автодеплой на GitHub Pages |

Сборки нет: чистовые HTML/CSS/JS, шрифты подгружаются с Google Fonts.

## Как добавить запись

1. Откройте `index.html` и найдите список `<ol class="entries">`.
2. Скопируйте любой блок `<li class="entry">…</li>` и вставьте рядом с остальными.
3. Замените заголовок, год, теги, статус и текст аннотации.

Номера записей (`01`, `02`, …) и их количество проставляются автоматически.
Статус задаётся атрибутом: `data-status="wip"` — в работе, `done` — завершено, `draft` — черновик.

## Локальный просмотр

Просто откройте `index.html` в браузере. Либо запустите локальный сервер:

```powershell
python -m http.server 8000
```

и откройте http://localhost:8000

## Публикация

Пуш в `main` → GitHub Actions собирает артефакт и публикует сайт (Pages, source: «GitHub Actions»).
Прогресс видно на вкладке **Actions**, адрес сайта — в **Settings → Pages**.

## Что стоит поменять под себя

- `index.html`: текст в шапке (`.masthead__lede`), факты (`.facts`), подвал (`.footer`) — там сейчас «Ваше имя» и ссылка на github.com.
- `index.html`: `<title>`, `<meta name="description">` и OG-теги.
- Строку «Обновлено» в блоке фактов.

## Важно про приватность

На бесплатном тарифе GitHub Pages работает только для **публичных** репозиториев.
Даже с приватным репозиторием на платном тарифе опубликованный сайт всё равно доступен всем по ссылке —
закрыть его средствами Pages нельзя.
